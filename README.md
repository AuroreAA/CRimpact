# `CRimpact`: Tools for Quantifying the Impact of Careless Responding

Set of functions and web application for quantifying the impact of careless responding, currently focused on the Pearson correlation coefficient.



## Installation

You can install the development version of `{CRimpact}` like so:

``` r
devtools::install_github("AuroreAA/CRimpact")
```

## Run

You can launch the application by running:

``` r
CRimpact::run_app()
```
